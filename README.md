# CCEE
기후변화와 환경생태

## 탄소 저감 과학기술 수업 챗봇 (1·2·3차시)

「AI와 논쟁하며 탄소 저감 과학기술 제안하기」 3차시 수업용 챗봇입니다. 학생은 한 주소에서 차시를 골라 시작합니다.

- **1차시 · 기술 탐구**: 정답을 알려 주지 않고, 소크라테스식 질문으로 기술 하나의 문제·원리·한계를 스스로 파악하게 한 뒤 나만의 탐구 질문과 정리 카드를 만들게 합니다.
- **2차시 · 비판적 토론**: 1차시 정리 카드를 이어 받아, 학생이 주장·근거를 세우고 AI의 반론을 직접 평가해 최종 판단을 수정하게 합니다. 대신 결론을 내리거나 답안을 써 주지 않습니다.
- **3차시 · 설계 심사**: 기존 기술의 한계에서 출발해 학생이 '탄소 저감 과학기술 2.0'을 직접 설계하고, AI 심사위원의 질문을 스스로 판단해 설계를 고친 뒤 수정 전후를 비교·성찰하게 합니다(8단계). 아이디어나 수정안을 대신 만들어 주지 않습니다.

| 위치 | 내용 |
|---|---|
| `prompts/lesson1_system_prompt.md` | 1차시 시스템 프롬프트(6단계 진행 규칙, 힌트 사다리, 자료 확인 규칙) |
| `prompts/lesson2_system_prompt.md` | 2차시 시스템 프롬프트(주장→근거→연결→반론→평가→최종 판단) |
| `prompts/lesson3_system_prompt.md` | 3차시 시스템 프롬프트(문제 확인→최초 설계→자기 점검→AI 심사→심사 판단→수정→최종 설계→비교·성찰) |
| `server/lessons.js` | 차시 목록(화면의 차시 이름, 시작 안내, 단계 이름) |
| `server/`, `public/` | 학생용 챗봇 서버와 채팅 화면 |
| `index.js`, `vercel.json` | Vercel 배포용 진입점과 설정(내 PC에서는 쓰지 않음) |
| `supabase/schema.sql` | (선택) 교사용 대화 기록, 학번으로 저장한 1차시 정리 카드 테이블 |
| `public/teacher.html` | (선택) 교사용 대화 기록 화면: 학생별·차시별로 읽기, 위기 신호·욕설 대화 먼저 보기, 다른 AI 글로 경고한 대화 모아 보기, 학생별·전체 학생 PDF로 저장(`TEACHER_CODE`, docs/DEPLOY.md 2-2) |
| `docs/DEPLOY.md` | **실행·배포·수업 전 점검표** |
| `tests/` | 모의 Anthropic 서버로 하는 자동 테스트 |

```
npm install
npm test            # 자동 테스트(API 키 불필요)
npm run demo        # 키 없이 화면만 미리 보기(모의 응답)
npm run check:api   # 실제 API 점검(.env에 ANTHROPIC_API_KEY 필요). 2·3차시는 npm run check:api -- 2 (또는 -- 3)
npm start           # 서버 실행 → http://localhost:3000
```

처음 설정은 [docs/DEPLOY.md](docs/DEPLOY.md)를 따라 주세요. `.env`(키가 들어 있는 파일)는 git에 올라가지 않으며, 키를 채팅이나 커밋에 붙여넣지 마세요.
